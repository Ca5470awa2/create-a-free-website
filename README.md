# create_a_web·studio

> 取个名字，就拥有一个网站。

一个轻量的在线建站平台。注册登录后，填一个名字、再确认一次密码，你的网站就诞生了 —— 接下来上传文件、在线改代码、立刻打开看效果，也能逛别人的站、留言、点赞、攒积分换源码。

---

## 创建你的网站

- 每人最多 **5 个网站**，名字全站唯一，输入时实时检测有没有被占用
- 创建后会自动生成属于你自己的 `web/<网站名>/` 文件夹，上传、编辑、改名、删除都真实落在这里，用 FTP 直接放文件也能被认出来
- 可选一键模板（个人主页 / 作品集 / 简历页），也可以从空白开始
- 想要动态站？勾选「我要创建 PHP 网站」，就能上传 `.php`、`.ok`、`.lock` 等文件，并在编辑页里直接管理自己的 MySQL

## 在线编辑器

多文件 Tab、行号、本地语法高亮、Ctrl+S 保存、全屏模式、拖拽上传与进度条、新建文件夹、移动文件、重命名、单文件下载、整站 ZIP 导出与导入。写坏了也不用心疼，改完保存立刻生效。

还能给网站加封面、简介、标签，设公开 / 私密，生成分享卡片和二维码，或者做一条限时私密链接给朋友看。

## 逛站与互动

「所有网站」是一面卡片墙：封面、最新 / 热门 / 点赞排行、标签筛选和搜索。卡片上就能点赞、评论、举报、收藏、下载公开源码，不用点进去再找按钮。

评论区支持楼中楼回复、@提醒和配图；开发者论坛可以发帖交流；关注作者后能私信，作者还能设置自动回复。有人评论或点赞你的站，消息中心会有红点提醒。作者主页可以自己布置标题、介绍、封面和外链。

## 积分与源码

每天有 **10 个每日任务**，每个最多 500 积分，做做就有。公开源码时可以自己定下载所需积分（默认上限 1000，网站点赞超过 100 就解锁到 5000），别人下载时积分会全额转给你，你也会收到通知；同一人买过一次就能反复下载。

## 代码库

每人最多 **5 个项目**：创建、搜索、星标、管理文件、发行版本。项目页里有一个 `Languages` 面板，按文件字节数统计语言占比，堆叠色条加双列图例，配色对齐 GitHub linguist。

## 一些小细节

- 7 种界面语言：简体中文、繁體中文、English、日本語、한국어、Español、Français
- 折叠菜单、深浅主题、全站内联 SVG 图标、可以添加到主屏幕
- 动效只动 `transform / opacity`，系统开了「减少动态效果」就自动安静下来
- 邮箱注册与找回密码、改密码、个人资料
- 基于 **PHP + MySQL**，不依赖 Composer、不请求外部 CDN，免费主机就能跑
